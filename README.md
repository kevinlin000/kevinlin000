### 🚲 YouBike Traffic Prediction System
**Solo Project** | *System Architecture, ETL & Backend AI Integration*（全端資料工程與流量預測系統）

> End-to-end system on GCP addressing the "supply-demand mismatch" in urban bike-sharing networks, processing **4M+ records**.

- 🏗️ Containerized environment on **GCP Compute Engine** with **Docker Compose**
- ⏱️ **Airflow** orchestration with a **10-minute micro-batch strategy** + auto-retry — high availability for continuous ingestion
- 📊 Validated "resource misallocation" (CV=0.78 at peak) as root cause via **ANOVA & T-tests**
- 🧠 **Multi-Station LSTM** with **Entity Embeddings** capturing spatial dependencies — MSE Loss **0.0071**
- ⚡ Real-time predictions served via **FastAPI**

### 🥗 Carbon Footprint Calculator
**Core Contributor** | *High-Performance Crawling & Data Cleaning*（食譜碳排計算引擎）

> Data ingestion layer for a carbon footprint analysis platform, solving complex unstructured data challenges.

- 🕷️ Asynchronous **Scrapy** spider — **10x speedup** vs. synchronous Selenium for 10,000+ recipes
- 🤖 "Lookup First, Ask AI Later" strategy: local dictionary + **Google Gemini API** to normalize ambiguous units（"1 spoon" → "15g"）
- 🔗 **Fuzzy Matching** (difflib) mapping heterogeneous Recipe ↔ Carbon Emission databases
